```cpp
class FLengthPrefixedParser
{
public:
    void AppendAndParse(const TArray<uint8>& NewData);
```

# 评分标准

## 概念与选择题

- 结论正确且给出因果关系：满分。
- 结论正确但只有背诵式短句：约一半分数。
- 使用“TCP 一定慢、UDP 一定快”“Ping 通说明服务正常”等绝对化错误：不得对应关键分。

## 故障分析题

- 能区分事实、推测和验证手段：高分。
- 能按层次缩小范围，而不是罗列无关原因：高分。
- 只写一个未经验证的唯一原因：低分。

## 代码题

- 正确处理输入不完整、长度越界和多消息：关键分。
- 状态字段和控制流清晰：过程分。
- 不要求生产级内存优化，但不得越界读取或无限分配内存。

## UE 情景题

- 明确客户端即时表现与服务器最终裁决：关键分。
- 能区分高频状态和关键事件：关键分。
- 能说明弱网下的降级表现和排查证据：加分。
