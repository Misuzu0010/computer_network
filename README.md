# 计算机网络学习笔记

本仓库用于记录面向工程与就业的计算机网络基础学习，不包含 Unreal Engine 专项内容。

当前目标是打牢网络通信、协议理解、抓包分析与问题排查能力；完成基础阶段后，再单独进入 UE 多人网络专项学习。

## 学习重点

- 网络分层、IP、端口、DNS、HTTP、TCP 和 UDP。
- 使用网络工具观察真实通信并进行分层排错。
- 基础网络编程、安全与线上服务认知。
- 不以考研式公式记忆或底层网络工程师方向为目标。
